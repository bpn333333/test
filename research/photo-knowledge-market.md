# 写真ナレッジ(撮影方法などの知識)の市場規模 — 調査メモ

作成: 2026-08-20
目的: 「写真の撮り方」等のナレッジを商品化した場合の市場の大きさと、個人が現実に取れる額を見積もる。

---

## 0. 結論(先に数字)

| 範囲 | 規模 | 確度 |
|---|---|---|
| **世界のオンライン写真教育** | **2030年に約 15億ドル(約2,200億円)**、年率 **9.3%** 成長 | 公表値 |
| 世界の写真市場「全体」(機材・サービス含む) | 2023年 約1,052億ドル → 2030年 1,618億ドル(CAGR 4.4%) | 公表値 |
| **日本の写真ナレッジ市場(教室+書籍+オンライン)** | **推計 100〜200億円/年**(趣味向けのみなら 70〜150億円) | **本メモの推計** |
| うち個人が参入できるオンライン部分 | **推計 10〜20億円/年** | **本メモの推計** |
| 個人1人が現実的に取れる年商の上限帯 | **年 100〜300万円**(上位2割の水準) | **本メモの推計** |

**要点: 「写真ナレッジ」は、世界で見れば成長市場だが、日本の個人が単体で食える大きさではない。**
月55万の穴を埋める主力にはならず、他商品との併売か、単価が一桁違うBtoB用途に寄せない限り成立しない。

## 1. 世界(公表値ベース)

- **オンライン写真教育**: 2030年に **約15億ドル**(≒2,200億円)。年率 **9.3%** 成長。
  別推計では2030年 8.25億ドル・年率5.6% と、機関により2倍近い開きがある(定義の広狭による)。
- **高等教育内のオンライン写真教育**: 2021→2026年で **+6億5,508万ドル**、CAGR **7.08%**。
- **写真市場全体**: 2023年 **1,052億ドル** → 2030年 **1,618億ドル**(CAGR 4.4%)。
  うち米国の写真業界単体で **158億ドル**(2026年)。
- **写真家の収入構成**(2026年、収益が安定している事業者):
  クライアント案件 **60%** / プリント販売 15% / **教育・ワークショップ 12%** / ストック 8% / アフィリエイト・物販 5%。

> ここが最も実務的な数字。**成功している写真家でも「教育」は収入の12%**にすぎない。
> ナレッジ単体で立つ商売ではなく、撮影業と束ねて初めて成立する収益源、というのが業界の実態。

## 2. 日本(直接統計が存在しない → 周辺統計から推計)

### 2-1. 使える周辺統計(すべて公表値)

| 指標 | 値 | 出所年 |
|---|---|---|
| アマチュア写真市場(プリント・フォトブック等の「出力」中心) | **1,617億円**(前年比99%) | 2024年度・JPIA |
| カルチャーセンター市場 | 330億円(2022年度)→ **360億円**(2023年度予測) | 矢野経済研究所 |
| eラーニング市場(BtoB中心) | **3,849億円**(前年度比+1.0%) | 2025年度・矢野経済研究所 |
| 教育産業市場 全体(主要15分野) | **2兆8,720億円**(前年度比+0.6%) | 2025年度・矢野経済研究所 |
| デジタルカメラ 国内向け出荷 | **99万6,328台**(前年比98.4%) | 2025年・CIPA |
| デジタルカメラ 世界総出荷 | 943万8,876台(前年比111.2%)/ うちレンズ交換式 700万1,965台 | 2025年・CIPA |
| 写真教室の相場 | 1回90〜120分で **5,000〜6,000円** | 2026年・ゼヒトモ |

注: **JPIAの1,617億円を「写真ナレッジの市場」と読んではいけない。** 中身はプリント・フォトブックなどの
出力サービスであり、撮り方を教える市場ではない。混同すると市場を10倍以上に見誤る。

### 2-2. ボトムアップ推計(本メモの試算・前提は明記)

| セグメント | 推計 | 前提 |
|---|---|---|
| カルチャーセンター内の写真講座 | 15〜25億円 | 市場360億円 × 写真カテゴリ比率 5〜7% |
| 独立系写真教室・撮影会・ワークショップ | 30〜60億円 | 年間受講者 20〜40万人 × 平均単価 1.5万円 |
| 写真専門学校・職業スクール | 50〜80億円 | 職業教育。趣味向け市場と分けて扱う |
| 書籍・ムック・雑誌 | 20〜40億円 | 入門書は継続、雑誌は縮小(主要カメラ誌は休刊済) |
| オンライン講座・サブスク・note/Brain・サロン | 10〜20億円 | ストアカ/miroom等プラットフォームの写真カテゴリ規模から |
| **合計** | **125〜225億円** | 趣味向けのみ(専門学校を除く)なら **75〜145億円** |

→ **日本の写真ナレッジ市場は、丸めて 100〜200億円**。教育産業全体 2.87兆円の **0.5%以下**、
カルチャーセンター1業態(360億円)にも満たない。**ニッチであることが最初の事実。**

### 2-3. 母集団の確認

- 国内デジカメ出荷 約100万台/年、買い替えサイクル5年 → **能動的な機材ユーザーは150〜300万人**規模。
- スマホで「上手く撮りたい」層は数千万人いるが、**支払意欲がほぼゼロ**(無料YouTubeで足りる)。
- 有料学習に到達するのは機材ユーザーの5〜10%、**年間10〜30万人**が実質の顧客母集団。

## 3. 構造的な難点(数字より重要)

1. **無料コンテンツの圧力が全ジャンル最強クラス。** 撮影技術は映像で見せた方が伝わるため、
   YouTubeが一次情報源として完成しており、テキスト有料商材の勝ち目が薄い。
2. **供給過剰。** ストアカだけで写真講師は多数在籍し、上位講師が受講者を寡占(1人で1,500〜2,000人規模)。
   10〜20億円のオンライン市場に数千人が乗るため、**平均取り分は年数十万円**。上位2割で年100〜300万円。
3. **成果が測りにくい。** 「収入が増えた」「試験に受かった」と違い、写真は上達を数値化できないため
   高単価化しにくい。相場が1回5,000〜6,000円に固定されている理由がこれ。
4. **参入障壁がない代わりに、権威が効く。** 作品・受賞・媒体掲載がない状態からの新規参入は不利。

---

## 4. 単価が一桁違う隣接領域(狙うならここ)

同じ「撮影ナレッジ」でも、買い手を趣味人から事業者に変えると単価が10倍前後変わる。

| 領域 | 単価目安 | 買い手の動機 |
|---|---|---|
| 趣味向け写真講座 | 5,000〜6,000円/回 | 楽しみ(支払意欲 低) |
| フォトツアー・撮影旅行 | 5〜15万円/人 | 体験(旅行予算から出る) |
| **EC物撮り・SNS運用の内製化研修(BtoB)** | **数十万円/社** | **売上に直結(研修予算から出る)** |
| レタッチ・Lightroom・生成AI×画像編集 | 中〜高 | 業務効率(現在最も伸びている) |

**企業向け研修サービス市場は2025年度もプラス成長分野。** 趣味向け写真ナレッジは伸び悩む一方、
「撮影を業務としてやる人向け」は教育産業の成長側に乗っている。

## 5. 本件プロジェクト(PLAN.md)の文脈での読み方

- 写真ナレッジ単体では、**10月からの新規収入55万円/月の穴埋めにはならない**。
  市場が100〜200億円、個人シェアの上限帯が年100〜300万円のため、月換算で最大でも数万〜20万円台。
- したがって位置づけは **第3弾以降の候補**。PLAN.md の優先順位(9月末までは案件獲得が本業、
  Kindleは管理職向けAI、トレード教材が第2弾)を動かす根拠にはならない。
- ただし **BtoB(EC物撮り・SNS内製化研修)に振ると、「管理職向けAI研修」と営業ルートが同一**になる。
  同じ法人・同じ研修予算に対して2商品を提案できるため、やるならこの形。趣味向け講座では接続しない。

## 7. 本メモの限界

- **日本の「写真ナレッジ」だけを切り出した公表統計は存在しない。** 第2節の内訳は周辺統計からの
  ボトムアップ推計であり、前提(受講者数・単価・カテゴリ比率)を変えれば数字は上下する。
- 世界のオンライン写真教育も、機関により2030年予測が 8.25億ドル〜15億ドルと2倍近く開く。
  「オンライン写真教育」に何を含めるかの定義差なので、**桁(1,000〜2,000億円台)だけを信用する**のが安全。
- JPIAの1,617億円は出力サービス中心であり、ナレッジ市場ではない(再掲)。
