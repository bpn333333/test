# rdcontrol — ローカルデスクトップのリモート操作アプリ

自分の PC でサーバーを起動すると、別の端末のブラウザからその PC の画面を見て操作できます。
接続する側に必要なのはブラウザだけです。

```
[操作する端末のブラウザ]  ──WebSocket──▶  [rdcontrol サーバー]  ──▶ 自分のデスクトップ
        画面(JPEG)      ◀──────────────      画面キャプチャ / 入力再生
```

---

## 使い方

### 手順 1: 操作される PC で起動する

```bash
cd remote-desktop
./run.sh                # 初回は仮想環境の作成と依存インストールも行う
```

Windows(PowerShell)は次のとおり。**先頭の `.\` が必要**です
(PowerShell はカレントディレクトリのコマンドを既定で実行しないため、
付けないと "The term 'run.bat' is not recognized" になります):

```powershell
cd remote-desktop
.\run.bat
```

起動すると、開くべき URL とトークンが表示されます。トークンは起動のたびに変わります。

```
  ■ このマシンのブラウザで開く
      http://127.0.0.1:8765/?token=Xk3n...

  ■ 別の端末から使う(SSH トンネル経由)
      1) 操作する側の端末で次を実行し、つないだままにする
         ssh -N ... -L 8765:127.0.0.1:8765 nori@desktop.local
      2) その端末のブラウザで次を開く
         http://127.0.0.1:8765/?token=Xk3n...
```

### 手順 2: つなぐ

**A. 同じ PC のブラウザから** — 表示された URL をそのまま開くだけです
(`--open` を付けて起動すれば自動で開きます)。

**B. 別の端末・スマホから(外出先でも同じ手順)**

[Tailscale](https://tailscale.com/download) を PC とその端末の両方に入れ、同じアカウントでログインします
(無料で使えます)。そのうえで `--tailscale` を付けて起動するだけです。

```bash
./run.sh --tailscale --token mytoken123     # Windows は .\run.bat --tailscale --token mytoken123
```

起動時に、そのまま開ける URL と **QR コード**が表示されます。
スマホのカメラで QR を読み取れば、URL を打ち写す必要はありません。

```
  ■ 外出先・スマホから開く(Tailscale 経由)
      http://100.〇〇.〇〇.〇〇:8765/?token=mytoken123   ← 実際の数字は PC ごとに違います

      ↓ スマホのカメラで読み取れます
       ▄▄▄▄▄▄▄ ▄   ▄▄    ▄▄  ▄▄▄▄▄▄▄
       █ ▄▄▄ █ ▀█▀▄ ██▄██  █ █ ▄▄▄ █
       …
```

> ルーターのポート開放は不要で、通信は Tailscale(WireGuard)が暗号化します。
> 同じ Tailscale アカウントにログインした端末からしか到達できません。
> `--tailscale` は Tailscale のアドレスにだけ待ち受けるため、同じ Wi-Fi にいるだけの
> 無関係な端末からは見えません。
>
> SSH で入れる相手なら [SSH トンネル](#ssh-トンネルで使う)も使えます(スマホには不向き)。

### 手順 3: 操作する

| 画面の項目 | 説明 |
| --- | --- |
| **キーボード転送: OFF/ON** | ON にすると押したキーが相手の PC に送られます。既定は OFF |
| **下部のキーボタン** | Esc / Tab / Enter / ⌫ / 矢印 / Win / Ctrl+C / Ctrl+V / Alt+Tab。ブラウザや OS に奪われる組み合わせはここから送ります |
| **⌨ 入力** | スマホ・タブレットでソフトキーボードを開く(タッチ端末でのみ表示) |
| **🔊 音声** | 操作している PC の音を、手元の端末で鳴らす(押したときだけ送ります) |
| **⛶ 全画面** | 上下のバーを隠して画面いっぱいに表示(対応環境では本来の全画面表示も併用) |
| **画質 / FPS / 解像度** | 回線が細いときは解像度と FPS を下げると安定します |
| **モニタ** | 複数モニタがある場合の表示切り替え |
| **全画面** | 画面部分だけをフルスクリーン表示 |

マウスは移動・左右中クリック・ドラッグ・ホイールがそのまま使えます。
相手のマウスポインタは画面に重ねて表示されます(画面キャプチャにはポインタが写らないため、
位置を別に受け取って描いています)。

**スマホ・タブレット(iPhone / iPad / Android)**

| 操作 | 動作 |
| --- | --- |
| タップ | 左クリック |
| 長押し(0.5 秒) | 右クリック |
| 指を滑らせる | ドラッグ |
| 2 本指で上下 | スクロール |

**同時接続**: 画面を見られるのは既定で 4 台まで(`--max-clients` で変更)。
ただし**操作できるのは常に 1 台だけ**で、2 台目以降は「閲覧のみ」バッジが付きます
(2 人が同時にマウスを動かすと操作不能になるため)。操作中の端末が切断すると、
次の端末へ自動的に操作権が移ります。

終了はサーバー側のターミナルで **Ctrl+C**。止めれば外部からの経路は完全に閉じます。

## 主なオプション

`./run.sh --view-only`(Windows は `.\run.bat --view-only`)のように、そのまま渡せます。

| オプション | 説明 |
| --- | --- |
| `--view-only` | 画面共有のみ。マウス・キーボード操作を一切受け付けない |
| `--no-audio` | 音声を一切送らない(既定は、接続側が 🔊 を押したときだけ送る) |
| `--monitor N` | 表示するモニタ番号(`0` は全モニタ結合)。一覧は `--list-monitors` |
| `--fps N` / `--quality N` / `--scale F` | フレームレート 1〜30(既定 10)/ JPEG 品質 10〜95(既定 60)/ 送信解像度の倍率 0.2〜1.0(既定 1.0) |
| `--port N` | ポート(既定 8765) |
| `--token XXX` | トークンを固定する(既定は毎回ランダム) |
| `--max-clients N` | 同時接続数の上限(既定 4) |
| `--ssh-target user@host` | 起動時に表示する SSH 接続先(既定は自動推定) |
| `--open` | 起動後にブラウザを自動で開く |
| `--diagnose` | カーソル位置のずれを実測して表示し終了する |
| `--tailscale` | Tailscale のアドレスで待ち受ける(外出先・スマホから使う場合はこれ) |
| `--host` | 待ち受けアドレス(既定 `127.0.0.1`)。LAN 内で使う場合のみ `0.0.0.0` |

## スマホ・タブレットから使う

上の **手順 2-B(Tailscale)** がそのまま使えます。iPhone / iPad には標準の SSH クライアントが
無いため、トンネルではなく Tailscale を使ってください。

1. PC とスマホの両方に Tailscale を入れ、同じアカウントでログインする
2. PC 側で `./run.sh --tailscale --token mytoken123`(Windows は `.\run.bat ...`)
3. スマホのカメラで、PC に表示された QR コードを読み取る
   (手で開く場合は、表示された `http://100.〇〇.〇〇.〇〇:8765/?token=...` をそのまま入力。
   数字は PC ごとに違うので、ドキュメントの例をそのまま打っても繋がりません)

タッチ操作に対応しています。

| 操作 | 動作 |
| --- | --- |
| タップ | 左クリック |
| 長押し(0.5 秒) | 右クリック |
| 指を滑らせる | ドラッグ |
| 2 本指で上下 | スクロール(等倍のとき) |
| 2 本指を広げる / つまむ | 表示の拡大・縮小(最大 5 倍)。指の間の位置を保ったまま拡大します |
| 拡大中に 2 本指で動かす | 表示位置の移動 |
| **✋ 表示移動** を押してから 1 本指 | 表示位置の移動(2 本指がやりにくいとき用) |
| **⤢ 100%** ボタン | 拡大を元に戻す |
| **✋ 表示移動** ボタン | 1 本指で表示位置を動かすモードに切り替える(操作は送りません) |
| **🔊 音声** ボタン | PC の音を iPhone で鳴らす |
| **⛶ 全画面** ボタン | バーを隠して画面いっぱいに使う |
| **⌨ 入力** ボタン | スマホのキーボードを開く。日本語入力(変換)もそのまま送れます |

文字入力は、上部の **⌨ 入力** ボタンを押してキーボードを出してから打ちます
(このボタンはタッチ操作の端末でだけ表示されます)。Enter / ⌫ / 矢印キーは
画面下部のボタンからも送れます。

> 画面が小さいので `--scale 0.6` で送信解像度を下げると軽くなります。
> 横向きにするとデスクトップが大きく映って操作しやすくなります。
> 細かい部分を触るときは、ピンチで拡大してからタップすると狙いやすくなります
> (拡大しても、送る座標は元の画面に合わせて計算されるのでずれません)。

**iPhone でさらに広く使うには**: **Safari** の共有ボタン →「ホーム画面に追加」で追加し、
そのアイコンから起動すると、アドレスバーが出ない状態(全画面)で使えます。
URL(トークンを含む)ごと保存されるので、`--token` でトークンを固定しておくと毎回そのまま開けます。
Chrome や Brave など Safari 以外のブラウザでは、この項目が共有メニューに出ない、
または出ても全画面にならないことがあります。その場合は Safari で開き直してください。

**音声について**: 🔊 音声 ボタンを押した端末にだけ送ります(押すまでは録りません)。
Windows は追加設定なしでスピーカーの音を取り込めます。macOS は BlackHole などの
仮想オーディオ機器、Linux は PulseAudio の monitor を既定の入力にする必要があります。
サーバー側で完全に禁止するには `--no-audio` を付けて起動してください。

### 自宅の Wi-Fi 内だけで使う(Tailscale なし)

信頼できる LAN 内に限り、`--host 0.0.0.0` でも使えます。起動時に表示される
`http://192.168.x.x:8765/?token=...` を開いてください。初回は Windows Defender
ファイアウォールの確認が出るので、**プライベートネットワーク**にチェックして許可します。
この経路は暗号化されないため、外出先では使わないでください。

## SSH トンネルで使う

Tailscale を使わず、SSH で入れる相手(自分の Linux / macOS / Windows PC など)に
つなぐ場合の方法です。パソコン同士向けで、スマホには向きません。

操作する側の端末でトンネルを張り、つないだままにします:

```bash
./tunnel.sh nori@desktop.local          # Windows(PowerShell)は .\tunnel.bat
./tunnel.sh mydesk 8765 9000            # 手元の 8765 が埋まっている場合
```

その端末のブラウザで `http://127.0.0.1:8765/?token=...` を開きます。サーバー側は
既定のまま(`127.0.0.1` で待ち受け)で構いません。外から SSH で入れるようにするには、
ルーターで SSH(22 番)だけを転送し、**必ず公開鍵認証のみ**にしてください
(`/etc/ssh/sshd_config` で `PasswordAuthentication no`、`PermitRootLogin no`)。

接続先を毎回打たずに済ませるには `~/.ssh/config` に登録します。以降は `./tunnel.sh mydesk` だけです。

```
Host mydesk
    HostName desktop.example.com
    User nori
    ServerAliveInterval 30
```

回線が不安定でトンネルがよく切れるなら `autossh` が使えます:

```bash
autossh -M 0 -N -o ExitOnForwardFailure=yes -o ServerAliveInterval=30 -L 8765:127.0.0.1:8765 mydesk
```

## 更新のしかた

このアプリを新しい版に入れ替える手順です。

1. サーバーが動いているウィンドウで **Ctrl + C** を押して止める
2. 同じウィンドウで最新版を取り込む(`git pull` = GitHub 上の最新の中身を自分の PC にコピーする命令):

   ```powershell
   git pull
   ```

3. もう一度起動する(必要な追加パッケージは自動で入ります):

   ```powershell
   .\run.bat --tailscale --token mytoken123
   ```

4. スマホやブラウザで開いているページを再読み込みする

## 困ったとき

| 症状 | 対処 |
| --- | --- |
| `bind: Address already in use` | 手元の 8765 番が使用中。`./tunnel.sh mydesk 8765 9000` と手元だけ別ポートにして `http://127.0.0.1:9000/?token=...` を開く(サーバー側は変更不要) |
| ブラウザが「接続できません」 | トンネルのターミナルを閉じていないか確認。閉じると転送も切れます |
| PowerShell で `The term 'run.bat' is not recognized` | `.\run.bat` のように先頭に `.\` を付けて実行してください |
| 401 Unauthorized | URL の `token=` の後ろが、説明用の `...` のままになっていませんか。起動時に表示された実際の文字列を使ってください。折り返しでコピーが途中で切れた場合も同じです。毎回同じ URL にしたいなら `--token mytoken123 --open` で起動 |
| 401 が続いて直らない | 認証失敗 8 回で 5 分間ロックアウトされます。サーバーを再起動すればリセットされます |
| 放置すると固まる | 回線側で切断されています。トンネルを張り直すか `autossh` を使ってください |
| 画面が真っ黒 / 起動時にエラー | デスクトップにログインした状態で起動していますか。SSH 越しに起動しても画面は取得できません |
| 操作だけ効かない | macOS はアクセシビリティ、Windows は管理者権限のウィンドウが原因のことがあります(下記) |
| マウスオーバー(ホバー)が反応しない | 古い版の症状です。最新版に更新してください(Windows でのカーソル移動を `SendInput` に変更済み) |
| クリック位置がずれる | `--diagnose` でずれ量を実測できます。表示スケーリング(Windows の拡大縮小 125% など)が原因なら、その旨と対処が表示されます |
| 「閲覧のみ」と出て操作できない | 別のタブや端末が操作権を持っています。そちらを閉じてから再読み込みしてください |
| スマホでドラッグや表示移動が効かない | 古い版の症状です(ページ自体がスクロールしてしまい、指の動きが奪われていました)。最新版に更新してください。それでも動かしにくいときは **✋ 表示移動** を使ってください |
| スマホから開けない | `--tailscale` で起動し、スマホ側でも Tailscale が接続中になっていますか。LAN 内で使う場合は `--host 0.0.0.0` と、Windows ファイアウォールでのプライベートネットワーク許可が必要です |
| `Tailscale のアドレスが見つかりません` | Tailscale が起動しログイン済みか確認してください。`tailscale ip -4` で 100.x.x.x が出れば正常です |
| スマホで真っ白 / タイムアウトになる | ドキュメントに書かれた例のアドレスをそのまま開いていませんか。アドレスは PC ごとに違います。**PC の起動画面に表示された QR コードを読み取るのが確実です** |
| QR が文字化けする / 表示されない | 日本語 Windows の既定(cp932)では表示できません。`chcp 65001` で UTF-8 にしてから起動してください |
| Tailscale を使わずすぐ試したい | 同じ Wi-Fi なら `.\run.bat --host 0.0.0.0 --token mytoken123`。表示された `http://192.168.x.x:8765/?token=...` をスマホで開きます(暗号化されないので自宅 LAN 限定) |

## 動作要件

- Python 3.10 以上
- **デスクトップにログイン済みのセッション**で実行すること(ヘッドレス環境では画面を取得できません)
- **macOS**: 「システム設定 → プライバシーとセキュリティ」で、実行するターミナルに
  **画面収録**(表示用)と**アクセシビリティ**(操作用)を許可
- **Windows**: 追加設定は不要。ただし管理者権限のウィンドウ(UAC など)を操作するには管理者として起動が必要
- **Linux**: X11 が必要(Wayland では動作しません。Xorg セッションでログインしてください)

## セキュリティ設計

デスクトップを丸ごと操作可能にするため、既定値を安全側に倒しています。

- **既定はループバックのみ** — `--host` を変えない限り外部から接続できません
- **トークン必須** — ページと WebSocket の両方で検証(`secrets.compare_digest` による定時間比較)
- **総当たり防御** — 接続元ごとに認証失敗を数え、8 回で 5 分間ロックアウト
- **入力の検証** — 受信 JSON は型・範囲・列挙値をすべて検証してからデバイス操作へ渡す
- **押しっぱなし防止** — 切断時やタブが非表示になったとき、押されたままのキー・ボタンを必ず解放
- **暗号化はアプリ外** — TLS は持ちません。他端末から使うときは Tailscale(WireGuard)か
  SSH トンネルを経由し、暗号化と相手の認証はそちらに任せます

<details>
<summary>通信プロトコル</summary>

WebSocket `/ws?token=...` の 1 本で双方向にやり取りします。

**サーバー → クライアント**

- バイナリ: 先頭 1 バイトが種別(`0x01` = JPEG 画像、`0x02` = 音声 PCM モノラル 24kHz 16bit)
- `{"t":"hello", ...}`: 接続直後の初期情報(操作権の有無、モニタ一覧、初期設定)
- `{"t":"config", ...}`: 設定変更の反映結果 / `{"t":"pong"}` / `{"t":"error","message":"..."}`

**クライアント → サーバー**(座標はすべて 0.0〜1.0 に正規化)

| メッセージ | 内容 |
| --- | --- |
| `{"t":"mouse_move","x":,"y":}` | マウス移動 |
| `{"t":"mouse_down"/"mouse_up","x":,"y":,"button":"left"\|"right"\|"middle"}` | ボタン押下・解放 |
| `{"t":"scroll","x":,"y":,"dx":,"dy":}` | ホイール(ノッチ単位) |
| `{"t":"key_down"/"key_up","key":,"code":}` | キー操作(`KeyboardEvent` の値) |
| `{"t":"text","text":"..."}` | 文字列をまとめて入力 |
| `{"t":"config","quality":,"fps":,"scale":,"monitor":}` | 表示設定の変更 / `{"t":"ping"}` |
| `{"t":"audio","enabled":true/false}` | 音声の受け取り開始・停止 |

座標を正規化して送るため、送信解像度を途中で変えてもサーバー側の座標計算は影響を受けません。

</details>

## 現時点の制限

- クリップボード共有・ファイル転送は未対応
- 音声はモノラル 24kHz(会議や動画の音を聞く用途向け。音楽鑑賞の音質ではありません)
- Wayland では動作しません(X11 セッションが必要)
- 動画のような激しい画面変化では帯域を多く使います(差分エンコード / WebRTC は未実装)。解像度と FPS で調整してください
- TLS 終端は行いません。HTTPS のリバースプロキシ配下に置くと、接続元 IP がプロキシのものになるため
  認証失敗のロックアウトが全接続者で共有されます(`X-Forwarded-For` は未対応)
