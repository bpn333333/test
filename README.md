## 0. 事業の定義（2026-09-08 確定）

**中国を中心に世界のAIクリエイターが自由に投稿し、課金と視聴で稼げるプラットフォームを運営する。**
**企業案件は当社が受注し、登録クリエイターへ配分する。**

| | ライン | 型 | 開始 |
|---|---|---|---|
| **P1** | 企業案件の受注 → クリエイターへ配分 | フロー・差益 | **初日から** |
| **P2** | 視聴課金の当社取り分 | ストック | **6ヶ月目（2027/4）〜** |
| **P3** | **広告収益（リワードで1話アンロック）** | 非連動 | **PF公開と同時（6ヶ月目）〜** |
| P4 | 制作ツール・モデルの外販 | ストック | 3年目〜 |

**設計の要:** 両面市場のコールドスタートを **P1 が解く**。P1 は視聴者を必要としないので、
トラフィックがゼロの初日からクリエイターに報酬を出せる。分成率で中国大手と殴り合わない唯一の設計。

### ⭐ 2026-09-09 決定 — 課金は BUMP 型（3択アンロック）

**1話の解放手段を3つ用意し、ユーザーに選ばせます。**国内1位の BUMP と同じ形です。

| ① 待つ | ② 広告を見る | ③ 課金する |
|---|---|---|
| 24時間で1話無料。収益ゼロだが**離脱を止める** | リワード広告1本で1話（**1日3回まで**）。実効eCPM ¥1,200 | 1話97円／コイン。ARPPU ¥3,000/月 |

**効果: 1MAUあたりの当社収益が ¥324/年 → ¥464/年（+43%）。損益分岐となる投放比率が 40% → 50% に上がります。**
**この上振れは計画本体に計上済みで、5期の目標を 売上33億・営業利益5億 → 売上37億・営業利益9億 に引き上げました。**
設計と数値の根拠は `PLATFORM_PIVOT.md` 第11章。

### 1-2. 1年目（2026/10〜2027/9）の使途 — 合計 **1億4,280万**

| 費目 | 万円 | 比率 |
|---|---:|---:|
| **視聴者獲得（流量投放）** | **4,800** | 34% |
| PF開発（アプリ・Web・課金） | 3,500 | 25% |
| 人件費（6名） | 3,000 | 21% |
| **分配原資の補填** | **1,500** | 11% |
| オフィス・SaaS・その他 | 480 | 3% |
| 設立・機材・その他初期 | 400 | 3% |
| 法務（資金決済法・規約・UGC対応） | 300 | 2% |
| インフラ（配信・ストレージ） | 300 | 2% |
| **合計** | **14,280** | 100% |

> **「人を集める」費用（流量投放 + 人件費 + 分配原資）で 66%。**
> ソフトウェアを作る費用は 1/4 しかない。高いのはPFではなく、PFに人がいない状態を買い戻す費用。
> インフラが安い根拠と、それでも1.5億が必要な理由は `PLATFORM_PIVOT.md` 第10章。

### 1-3. 5年計画（計画値・単位 百万円）

> **⭐ 2026-09-09: BUMP型の上振れを計上して引き上げました。**引き上げ前は 5期 3,300 / +500 です。

| | 1期 2027/9 | 2期 2028/9 | 3期 2029/9 | 4期 2030/9 | 5期 2031/9 |
|---|---:|---:|---:|---:|---:|
| 売上高 | 30 | 190 | 530 | 1,670 | **3,700** |
| 　うち P3 広告 | — | 12 | 60 | 270 | **600** |
| 営業利益 | ▲113 | **▲134** | ▲54 | +250 | **+900** |

- 赤字は **2期に最大化**し、3期から縮小に転じる
- **単月黒字化は4期**
- 5期の目標（**売上37億・営業利益9億**）は、グロースの上場維持基準「時価総額100億円」からの逆算（33億・5億）に、**BUMP型の上振れ400百万を上乗せ**したもの
- **⚠️ 増分400百万はすべて広告（P3）。eCPM ¥1,200 が外れると、そのまま消えます**
