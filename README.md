## 0. 事業の定義（2026-09-22 改定）

**日本企業から映像制作を受注し、中国を中心とする登録クリエイターの体制で制作する。**
**そこで溜まる制作データを内製化・特許・モデル開発につなげ、人手に比例しない収益へ移す。**
**自社プラットフォームは、制作した作品と日本IPの出口として副次的に運営する。**

| | ライン | 型 | 開始 | 位置づけ |
|---|---|---|---|---|
| **P1** | **映像制作の受注 → 登録クリエイターへ配分** | フロー・差益 | **初日から** | **主軸** |
| P2 | 自社PFの視聴課金（当社取り分） | ストック | 6ヶ月目（2027/4）〜 | 副次 |
| P3 | 自社PFの広告収益（リワードで1話アンロック） | 非連動 | 6ヶ月目〜 | 副次 |
| **P4** | **制作ツール・モデルの外販** | ストック | 3期〜 | **企業価値の担い手** |

**設計の要:** キャッシュと顧客とデータを生むのは **P1（制作受託）**。
ただし受託は売上が人手に比例するため、そのままでは上場しない（`BUSINESS_PLAN.md` 3-1）。
**だから「人手に比例しない収益」＝ P2・P3・P4 の比率を上げることを KPI に置く。5期で 44%。**

> ### ⭐ 2026-09-22 決定 — プラットフォームを主軸から副次へ戻しました
> 2026-09-08 に「受託BPO → プラットフォーム先行」へ転換しましたが、**本決定でこれを差し戻します。**
> 主軸は映像制作、プラットフォームは副次ラインです。経緯と旧設計は `PLATFORM_PIVOT.md`。
> **これに伴い 5期の目標を 売上37億・営業利益9億 → 売上18億・営業利益3.8億 に改めました。**

### ⚠️ アダルトは対象外です（2026-09-22 決定）

**受注する案件にも、自社PFに載せる作品にも、アダルトを含めません。**
理由は技術ではなく **決済・法規制・アプリストア審査**です。
決済代行とアプリ内課金がほぼ確実に通らず、PF側は年齢確認義務が重くなります。
制作単価は高い領域ですが、**上場を目指す以上ここは取りません。**

### 1-3. 5年計画（計画値・単位 百万円）

### 1-4. 上場

| 項目 | 確定値 |
|---|---|
| **上場申請** | **5期・2031年** |
| 市場 | **東証グロース** |
| 想定時価総額 | **中心値64億円**（試算レンジ 36〜103億） |
| N-2期の監査開始 | **3期・2028年10月** |
| 監査法人ショートレビュー | **2期（2028年）** |
| 維持基準 | 2030年3月以降「上場5年経過後に時価総額100億円」→ **2031年上場なら2036年に100億** |

> **⚠️ 上場時点では維持基準100億に届きません（中心値64億）。**
