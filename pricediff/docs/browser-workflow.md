# ブラウザで集めて貼り付ける運用

淘宝の API はほぼ取れず、Amazon の PA-API も販売実績がないと発行されません。
その間は **自分でブラウザを開いて見た数字を貼る** のが現実的です。
調べるのは人間（＋ブラウザ側のアシスタント）、計算と一覧化はこのツール、という分担にします。

```
Chrome で商品ページを開く
      ↓  ページを見て CSV 1行にしてもらう
CSV行をコピー
      ↓  pricediff add
watchlist.csv に追記
      ↓  pricediff run
価格差・重さ・ランキングの一覧
```

## 守ること

- **自分が開いたページを読む**のはこの範囲。ログインが要るページも、自分の画面で見る前提なら問題ありません
- **自動巡回・大量取得はしない。** 淘宝も Amazon も規約で禁じています。だからこのツールにも
  スクレイピング機能は入れていません。1日に数十件を手で見て回る規模に留めてください
- 取得した価格は**見た時点の値**です。仕入れ前に必ず実ページで再確認してください

---

## 手順1: 淘宝で仕入れ候補を見る

商品ページを開いた状態で、ブラウザ側のアシスタントに貼るプロンプト:

```
このページの商品について、以下のCSV1行だけを出力してください。説明文は不要です。

name,taobao_url,taobao_price_cny,weight_g,note

- name: 日本語の商品名（日本で検索するときの言い方。20字以内）
- taobao_url: このページのURL（?以降のパラメータは削って id= だけ残す）
- taobao_price_cny: 実際に支払う価格（元）。セール価格があればそれ。数字のみ
- weight_g: ページに記載があればグラム。無ければ空欄
- note: 最低ロットや色/サイズ違いの注意があれば10字以内で。無ければ空欄

商品名にカンマが入る場合は "..." で囲ってください。
```

複数商品をまとめて見てもらうときは「検索結果ページの上位10件について、同じ形式で10行」と指示します。

## 手順2: 日本側の価格とランキングを見る

**楽天はアプリIDがあれば自動で入る**ので、この手順は Amazon だけで構いません。

Amazon の商品ページで:

```
このページについて、以下のCSV1行だけを出力してください。説明文は不要です。

name,amazon_asin,amazon_price_jpy,amazon_rank,weight_g

- name: さきほど淘宝側で付けた商品名と同じ文字列
- amazon_asin: 商品情報欄のASIN
- amazon_price_jpy: 新品の販売価格（円）。数字のみ、カンマ無し
- amazon_rank: 「Amazon 売れ筋ランキング」の一番大きいカテゴリの順位。数字のみ
- weight_g: 商品の重量。ポンド表記ならグラムに換算（1ポンド=454g）
```

`amazon_rank` は商品ページ下部の「登録情報」内にあります（例: 「ホーム&キッチン - 8,420位」→ `8420`）。

## 手順3: 貼り付けて追記する

```bash
pricediff add -w watchlist.csv
```

CSV行を貼り付けて **Ctrl-D**。ファイルやクリップボードから流し込むこともできます:

```bash
pricediff add < rows.csv
pbpaste | pricediff add          # macOS
```

- 1行目がヘッダなら列名に従い、無ければ既定の列順とみなします
- **同じ商品（商品名か淘宝URLが一致）は自動で飛ばします**。二重登録の心配は不要です
- 価格だけ更新したいときは `--update`。**貼り付けた列だけ**が上書きされ、
  書かなかった列（楽天価格やランキングなど）は残ります

```bash
# 淘宝の価格が変わったので、その列だけ更新する
printf 'name,taobao_price_cny\n保温タンブラー,39.9\n' | pricediff add --update
```

- 書き込む前に確認したいときは `--dry-run`

## 手順4: 一覧を出す

```bash
pricediff run -f console,csv,html
```

楽天のアプリIDを設定してあれば、楽天の価格とランキングはここで自動で埋まります。

## 定期的に見直すとき

価格は動くので、候補として残した商品は週1回くらい見直します。

1. 淘宝ページを開いて価格だけ確認 → `name,taobao_price_cny` の2列で `pricediff add --update`
2. `pricediff run --sort ratio` で差率の高い順に並べ直す

楽天側はAPIで毎回自動更新されるので、手で触るのは淘宝とAmazonだけです。
